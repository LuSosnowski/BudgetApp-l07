# BudgetApp

Aplikacja BudgetApp służy do zarządzania wydatkami indywidualnymi oraz grupowymi. Projekt składa się z backendu napisanego w Java Spring Boot oraz frontendu napisanego w React.

## Funkcjonalności

- rejestracja i logowanie użytkowników,
- autoryzacja JWT,
- zarządzanie transakcjami użytkownika,
- bilans przychodów i wydatków,
- tworzenie grup,
- dodawanie członków do grup,
- dodawanie wydatków grupowych,
- wybór uczestników wydatku grupowego,
- obsługa długów między użytkownikami,
- oznaczanie długu jako opłaconego,
- potwierdzanie spłaty długu,
- powiadomienia WebSocket o nowych wydatkach grupowych.

## Technologie

- GraphQL,
- WebSocket,

- Maven.

Frontend:
